# Roadbook NG

**Roadbook NG** is an independent, public-interest guide for Nigerian drivers and vehicle owners.

It turns scattered motoring requirements into practical answers:

- What documents do I need?
- Which agency handles each one?
- How do I apply or verify it?
- What changes for private, commercial, ride-hailing, motorcycle or tricycle use?
- What should I check before buying a used vehicle?
- What rules and road-safety requirements should I know?
- Which claims are federal, and which depend on my state?

## Product principles

1. **Official sources first.** FRSC, NPF, NAICOM and other primary/industry-authoritative sources are linked directly.
2. **No fake certainty.** State-specific or contested requirements are labelled instead of guessed.
3. **No impersonation.** Roadbook NG does not issue licences, permits, insurance, number plates or government documents.
4. **No sensitive data.** V1 does not collect or store vehicle, licence, NIN or personal identity data.
5. **Mobile first.** The product is designed to be useful at home, at a licensing office, or on the road.

## V1

- Next.js 15
- React 19
- TypeScript
- Plain CSS (no UI framework)
- No database
- No environment variables required

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Important disclaimer

Roadbook NG is an independent educational product, not FRSC, NPF, VIO, NAICOM, a state motor licensing authority, or any other government agency. Laws, fees, enforcement positions and state procedures can change. Always confirm important actions on the linked official source.
